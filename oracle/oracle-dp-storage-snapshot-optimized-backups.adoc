= Backups optimizados para Snapshot de almacenamiento
:allow-uri-read: 


[role="lead"]
Las copias de seguridad optimizadas con instantáneas de Oracle eran un método de recuperación a un momento específico que permitía a un usuario realizar una recuperación mediante instantáneas sin poner la base de datos en modo de backup en caliente.

Los usuarios pueden seguir recuperando datos a partir de instantáneas sin necesidad de utilizar el modo de backup, pero solo se admite la recuperación completa mediante RECOVERY AUTOMATIC. La recuperación incompleta mediante el método SNAPSHOT TIME para indicar la hora de creación de la instantánea.
