= Backups de grupos de consistencia
:allow-uri-read: 


[role="lead"]
Para realizar un backup lo más sencillo posible, solo tienes que colocar toda la base de datos Oracle en un único volumen ONTAP, LUN o espacio de nombres NVMe.

Proteger los archivos de datos, los registros de archivo, los registros de rehacer y los archivos de control con una única snapshot es un método válido de backup, restauración y replicación. Sin embargo, el RPO se limita al punto de backup en sí mismo. Es adecuado para un RPO de una hora o más. Si una base de datos abarca volúmenes AFF o unidades de almacenamiento ASA, se requieren grupos de coherencia usando una de las herramientas mencionadas anteriormente.

Como ejemplo, toda la base de datos puede estar en un único volumen AFF con la siguiente programación de snapshots:

* 72 snapshots cada hora
* 30 snapshots por noche
* 12 snapshots mensuales


Esto proporciona un RPO de una hora durante el periodo móvil de las 72 horas anteriores, además de backups nocturnos y mensuales adicionales. También se pueden incluir varias bases de datos o archivos de aplicaciones en el único volumen o conjunto de snapshots de grupo de coherencia para ofrecer backups coherentes en un entorno más amplio.
